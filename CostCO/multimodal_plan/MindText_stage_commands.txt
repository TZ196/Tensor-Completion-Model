MindText CoSTCo staged experiment commands
=========================================

Directory layout:
  CostCO/multimodal_text/shared
    Common multimodal layers and experiment utilities.

  CostCO/multimodal_text/models/costco_text
    CoSTCo + text model and runner.

  CostCO/multimodal_text/models/gcn_costco_text
    GCN-CoSTCo + text model and runner.

Run Stage 1 from:
  cd CostCO/multimodal_text/models/costco_text

Run Stage 2/3 from:
  cd CostCO/multimodal_text/models/gcn_costco_text

Prerequisite:
  CostCO/multimodal_text/text_data/endo_text_embeddings.npy
  CostCO/multimodal_text/text_data/exo_text_embeddings.npy
  CostCO/splits/random_observed10_val10_seed_3.npz

Text preparation
----------------
Run from:
  cd CostCO/multimodal_text

python run_text_preparation_pipeline.py \
  --stage all \
  --topology-path ../sat_connectivity_tensor_dynamic_60s_1000ms.npz \
  --env-path deepseek.env \
  --config-path experiment_description.md \
  --embedding-model sentence-transformers/all-MiniLM-L6-v2 \
  --embedding-batch-size 32

The endogenous text preparation uses topology-only statistics from:
  text_data/time_stats_topo_only.json

Endogenous text is generated by a deterministic unified template and written to:
  text_data/endo_texts.json

DeepSeek is used only for exogenous text generation from experiment_description.md:
  text_data/exo_text_segments.json

Text embeddings are generated by:
  sentence-transformers/all-MiniLM-L6-v2

This model normally outputs 384-dimensional embeddings. The training runners
then use --text-projection-dim, usually 128, to project text features before
fusion.

The endogenous template does not read the traffic tensor, does not create a
random mask, and does not use train/validation/test split information. Random
masking is used only by the model training runners.

Stage 1: CoSTCo + text concat baseline
--------------------------------------
python run_text_sat_tensor_experiment.py \
  --rank 50 \
  --nc 64 \
  --text-stage concat \
  --text-projection-dim 128 \
  --lr 1e-3 \
  --epochs 200 \
  --batch-size 256 \
  --target-normalization max \
  --seed 3

Stage 2: GCN-CoSTCo + text concat baseline
------------------------------------------
python run_gcn_text_sat_tensor_experiment.py \
  --rank 50 \
  --nc 64 \
  --node-dim 64 \
  --gcn-dim 128 \
  --text-stage concat \
  --text-projection-dim 128 \
  --lr 1e-3 \
  --epochs 200 \
  --batch-size 256 \
  --target-normalization max \
  --seed 3

Stage 3a: Add cross-view text attention
---------------------------------------
Use the Stage 2 command and change:
  --text-stage cross_attention

Stage 3b: Add semantic gating
-----------------------------
Use the Stage 2 command and change:
  --text-stage semantic_gating

Stage 3c: Add segment-level content condenser
---------------------------------------------
Use the Stage 2 command and change/add:
  --text-stage segment_condenser \
  --condenser-alpha 0.5 \
  --condenser-epsilon 0.05 \
  --condenser-loss-weight 1e-4

Stage 3d: Add multimodal semantic alignment
-------------------------------------------
Use Stage 3a/3b/3c and add:
  --flow-text-loss-weight 0.01 \
  --graph-text-loss-weight 0.01 \
  --alignment-projection-dim 128 \
  --alignment-temperature 0.2 \
  --temporal-delta 2

Text ablations
--------------
Real text:
  --text-ablation real

Zero text:
  --text-ablation zero

Shuffle endogenous text by time:
  --text-ablation shuffle_endo

Random text vectors:
  --text-ablation random

Important notes
---------------
The runners load an existing split by default. They do not regenerate the
random mask unless --create-split is explicitly passed.

The text modality is combined endo+exo. Endogenous text is gathered by time
slice from topology-only text, and exogenous text is pooled or attended as a
small segment memory.

The projection layer is kept before fusion to prevent high-dimensional text
vectors from dominating CoSTCo or GCN features.
